# STREAMS OF GAMMAN

**Real-Time Stock Streaming Analytics**

Streams of GAMMAN is a local streaming data pipeline for analysing live US equity
trades. It ingests real-time market data into Redpanda, processes
event-time streams with Apache Flink, and visualises live OHLCV candles
and technical indicators through Streamlit.

The default watchlist tracks GOOGL, AAPL, META, MSFT, AMZN and NVDA,
while users can subscribe to other available US equities from the
dashboard.
